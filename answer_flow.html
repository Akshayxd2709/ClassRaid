Answer-to-Damage Flow

01
Validation
Server receives answer event, checks against Room Key and Topic.
02
Calculation
Correct answer triggers boss-hit logic (-12 HP). Wrong answer triggers player-recoil (-20 HP).
03
State Broadcast
Server emits boss_update or hp_update to all room members.
04
Animation Trigger
Frontend receives update and calls ClassRaidBattle.playHit() or playMiss().
