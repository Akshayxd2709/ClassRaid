Communication Gateway (Socket.IO)
Persistent Websocket
Manages 1:N connections per room code. Handles heartbeat and reconnection logic.
Room Logic
Partitions traffic by 4-digit code. Every student event is validated against the room owner (Teacher).
State Engine (Backend API)

Owns the truth: Boss HP, Question Queue, and Student Progress.
Logic Processor
Calculates damage from student answers, manages timers, and triggers peer-match pairing.
